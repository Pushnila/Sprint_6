# Sprint_6 — автотесты сервиса «Яндекс.Самокат»

Проект содержит UI-автотесты учебного сервиса «Яндекс.Самокат».

Тесты написаны на Python с использованием:

- Selenium;
- Pytest;
- Page Object Model;
- Allure;
- Mozilla Firefox.

## Проверяемые сценарии

### Раздел «Вопросы о важном»

Проверяется, что при нажатии на каждый вопрос отображается соответствующий текст ответа.

Для восьми вопросов применяется параметризация.

### Заказ самоката

Проверяется позитивный сценарий оформления заказа:

- переход к форме через верхнюю кнопку «Заказать»;
- переход к форме через нижнюю кнопку «Заказать»;
- заполнение первого шага формы;
- заполнение второго шага формы;
- подтверждение заказа;
- появление сообщения об успешном оформлении.

Тест запускается с двумя наборами данных.

### Навигация по логотипам

Проверяется:

- переход на главную страницу по логотипу Самоката;
- открытие главной страницы Дзена в новой вкладке по логотипу Яндекса.

## Структура проекта

- `pages/` — классы Page Object;
- `locators/` — локаторы, разделённые по страницам;
- `tests/` — автотесты;
- `conftest.py` — фикстура браузера Firefox;
- `data.py` — тестовые данные;
- `urls.py` — адреса страниц;
- `allure_results/` — результаты запуска тестов для Allure;
- `requirements.txt` — зависимости проекта.

## Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

## Запуск тестов

```bash
python -m pytest -v
```

## Создание результатов Allure

```bash
python -m pytest -v --alluredir=allure_results --clean-alluredir
```

## Просмотр Allure-отчёта

```bash
allure serve allure_results
```
